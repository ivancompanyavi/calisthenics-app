# OG2 Ch.10 — Methods of Progression

> **Source:** *Overcoming Gravity* 2e, Ch.10, book pp.115-136.
> **Verify:** `_sources/og2.txt` or PDF pp.115-136.
> **Tiers:** [SCIENCE] established research · [CONVENTION] Low's system · [DISPUTED] contested.

## Framing (p.115)
[CONVENTION] Two orthogonal axes of progression exist: **intra-exercise progression** (getting better within the same exercise: more reps, more load) and **inter-exercise progression** (moving from one exercise variation to a harder one in the same skill line, e.g. tuck planche → advanced tuck planche → straddle planche). All programming reduces to manipulating: repetitions, sets, rest, tempo, intensity/load, volume, frequency (p.115).

---

## Simple Intra-Exercise Progression (p.115)
[CONVENTION] "Intra-exercise" = transition from lower-reps/higher-intensity toward higher-reps/lower-intensity within one exercise. Rate of progress is exercise-specific — even two exercises hitting the same muscle group can progress at different rates, so track each exercise as its own entity, not a muscle-group aggregate (p.116).

### Linear Progression (p.116)
[CONVENTION] Add external load (vest, ankle/wrist weights, plates) across successive workouts while holding sets/reps fixed, e.g. 3x5 @0lb → 3x5 @10lb → 3x5 @20lb. Originated in barbell/dumbbell training; ported to bodyweight work most commonly for weighted pull-ups/dips because these tolerate significant external load and are the best brute-strength/mass builders among bodyweight moves (p.116).

### Linear Repetition Progression (p.116)
[CONVENTION] Add reps to all sets each workout without added load: 3x5 → 3x6 → 3x7 (across three separate workouts, not the same session). Recommended for beginners because early-stage progress is fast with basic exercises — this is *why* beginner routines are written as rep ranges (e.g. "3x5-15"): the range encodes the linear-rep-progression path, not a single target. Reasoning for range width: a wider range (5→15) favors hypertrophy because it accumulates more total volume before the athlete must change modality (p.116-117). Progress is expected to plateau after a few weeks as the body adapts to the fixed stimulus — signal to change programming, not push harder on the same scheme (p.117).

### Repetition Addition (p.117)
[CONVENTION] Slower method: increase reps in only one set at a time, spread across a week or more (assumes 3x/week full-body frequency), e.g. 5-5-5 → 6-5-5 → 6-6-5 → 6-6-6 → 7-6-6. Rationale: bridges the gap when an athlete *cannot* add a rep to every set simultaneously — decomposes one big jump into several small, achievable ones. Sets/reps need not stay symmetric or round; extra sets can be inserted freely, e.g. 6-6-5-5 (p.117-118).

### Last Set to Failure (p.118)
[CONVENTION] Keep all sets but the last short of failure; push only the final set to true failure. Mechanism/rationale: (a) strength is trained effectively by staying short of failure on most volume (fatigue management), so this method still nets a strength stimulus on non-final sets; (b) the failure set functions as a **fatigue/readiness gauge** — if the last set beats the first set's reps by ≥2, the athlete is cleared to progress to the next level; a small margin means not yet ready (p.118). Adaptive jump sizing: a large failure-set overshoot (e.g. 5-5-8) licenses skipping ahead to a bigger next step (7-7-7) rather than the standard +1 increment — the size of the failure-set beat is itself the progression-rate signal. Also doubles as a deload technique: keeping early sets deliberately submaximal while still probing true limits on the last set lets the athlete monitor recovery without risking overreach on volume (p.118).

### Additional Set (p.118)
[CONVENTION] Add whole sets rather than reps: 6-6-6 → 6-6-6-6 → 6-6-6-6-6. Rationale: particularly effective for pulling exercises (pull-ups, rows) because newer athletes' weak link is typically the back — added volume strengthens scapular musculature and "restarts" progress. Also cited for hypertrophy: when working reps are 1-8 (too low for direct hypertrophy volume), extra sets substitute for extra reps to hit hypertrophy-range total volume (p.118).

### Rest Pause (p.119)
[CONVENTION] Take a short, decreasing rest immediately after a near-/to-failure final set to squeeze out 1 extra rep, then progressively shrink that pause until the "bonus" rep merges into the main set. Example: 5-5-4-to-failure, +1 rep after 20s rest → same but 10s rest → eventually 5-5-5 with no rest, i.e., the gap closes entirely. Mechanism given: hitting the target total rep count (even split across a micro-rest) still drives the body to adapt to the target load/volume, so the split set gradually "unifies" as capacity rises (p.119).

### Density (p.119)
[CONVENTION] Definition: Density = Volume / Time, progressed by holding volume constant and shrinking the time component (chiefly rest between sets), e.g. 5-5-5 @4min rest → @3min → @2min, then repeat one rung higher in reps (6-6-6 @4min...). Interpretation: performing the same total reps in less time is evidence of increased work capacity. Book notes an alternate (nonstandard) framing — increasing volume within fixed time is *also* technically a density increase, but this isn't the term's conventional usage in the literature; author flags this as a naming/definition ambiguity, not a disputed mechanism (p.119).

### Tempo Change (p.119-120)
[CONVENTION] Progress by lengthening the eccentric portion of tempo across workouts while holding sets/reps fixed: 5-5-5 @10x0 → @20x0 → @30x0 (then repeat at 6-6-6). Mechanism: lengthening eccentric duration increases total time-under-tension for identical rep count — e.g., 15 reps × 1s eccentric = 15s TUT vs. 15 reps × 3s eccentric = 45s TUT — and this accumulated TUT is what permits higher rep counts in subsequent phases (p.120). The "X" (explosive concentric) is called out as generally the *most effective concentric tempo for strength training specifically*, though it may be swapped for aesthetic/skill goals (e.g., slow muscle-ups). Tempo can also be modified to add a top-position pause (10x0 → 10x2) to bias toward a specific isometric position (e.g., pseudo-planche hold via ring pseudo-planche pushups), or to strip the stretch-shortening/rebound assist at the bottom of the rep by eliminating the immediate concentric after the eccentric (10x0 → 11x0/12x0), which removes an elastic-energy assist and makes the rep purely strength-driven (p.120).

### Frequency Modifications / Grease the Groove (GTG) (p.120-121)
[CONVENTION] Explicitly *not* classified by the book as a true "method of progression" in the same family — it modifies session frequency rather than the load/volume variables above. Protocol: perform frequent submaximal sets of one exercise, many times per day, nearly every day, at ~60-80% of max reps per set (e.g., max = 4 dips → do 2-3 dips per set, 6-10× across the day ≈ 30 total daily reps, vs. ~15 total reps if confined to one workout session). Mechanism: [SCIENCE-adjacent per book] extremely high frequency "greases" the neurological groove — i.e., accelerates neural adaptation/motor pattern efficiency (referencing ch.2's neural-adaptation material) — producing fast strength/endurance gains, comparable to boot-camp-style daily pushup/sit-up volume (p.121). Staying submaximal is load-bearing: it avoids overworking while still providing high practice frequency. Constraint: GTG on one pushing exercise typically consumes recovery capacity for *all* pushing work that day — the book's convention is to drop other pushing exercises from the routine for the GTG duration, keeping pulling and leg work. Works well for concentric skills like pull-ups/dips and for statics like back lever and front lever, building up to ~8-10 reps before switching to strength/specific-endurance work. [DISPUTED/CONVENTION] Explicitly does **not** work for the planche — the planche's outsized relative-strength demand and reliance on small muscles means GTG-style daily frequency causes burnout before meaningful strength gain; only advanced athletes with much higher relative work capacity might get away with it, and it's not recommended generally (p.121).

### Transference to Isometric Holds and Eccentrics (p.121)
[CONVENTION] All the above methods transfer directly to isometric/eccentric training by substituting hold-duration or eccentric-duration for reps. Linear repetition progression example: 4x15s → 4x16s → 4x17s holds. Last-set-to-failure example given in seconds, same adaptive-jump logic (e.g., a big overshoot on the failure hold licenses skipping straight ahead by 3s rather than 1s) (p.121).

## Simple Inter-Exercise Progression (p.121)
[CONVENTION] Framed as the *harder* of the two progression types, because the strength gap between adjacent skill-line progressions grows sharply at higher difficulty (unlike low-level jumps, e.g. 10 strict pull-ups usually already supports 3-5 wide-grip pull-ups) (p.121-122).

### Weight Addition (p.121-122)
[CONVENTION] Add small increments of load to the *current* (easier) progression until removing the load makes the *next* (harder) progression feel comparatively easy. Example: advanced tuck planche holds progressively loaded with 1-4lb ankle weights, then straddle planche attempted unweighted. Rationale: builds strength/mass at the current level under artificially inflated demand so the true next-level bodyweight-only demand becomes sub-maximal by comparison (p.122).

### Assistance (p.122)
[CONVENTION] Reduce the effective difficulty of the *next* progression directly (bands, pulley systems) so the athlete can practice it immediately rather than waiting at the current level. Explicit requirement: assistance must be **measurable** — pulley systems are preferred because assistance weight can be logged and systematically reduced workout-to-workout. Partner assistance, bands, or finger-assistance for unilateral work are flagged as hard to quantify and therefore should be avoided where a measurable alternative exists, since unmeasured assistance breaks the ability to evaluate progress or plan future loading (p.122).

### Eccentric Exercises (p.122-123)
[CONVENTION] Use eccentrics of the *next* progression as a bridge, progressively lengthening hold duration: 3-5x3 reps @6s eccentric → …→ @10s, decreasing rest between sets as duration increases. Works particularly well for pulling exercises (pull-ups, one-arm chin-ups). Empirical rule stated: the ability to perform three 10-second eccentrics of a movement in a row predicts the ability to perform at least one concentric rep of that same movement — i.e., eccentric strength at that duration threshold is used as a readiness gate for attempting the concentric (p.123).

### Momentum and Extra Range of Motion (p.123-124)
[CONVENTION] Insert an intermediate skill that uses a *larger* range of motion plus momentum to bridge two static/skill positions that are otherwise too far apart (example: front lever row progressions). Protocol example (front lever rows): start from full pull-up position, pull through to the top of the *next* progression's position, lower to the bottom of a plain pull-up — this routes the shoulder through a bigger ROM and borrows strength from the easier pull-up bottom position to assist reaching the harder top position. Ordered example progression (p.124):
1. 3x8 Tuck Front Lever Row
2. 3x4 Pull-up to Advanced Tuck Front Lever Row Position
3. 3x5 Pull-up to Advanced Tuck Front Lever Row Position
4. 3x6 Pull-up to Advanced Tuck Front Lever Row Position
5. 3x7 Pull-up to Advanced Tuck Front Lever Row Position
6. 3x8 Pull-up to Advanced Tuck Front Lever Row Position
7. 3x4 Advanced Tuck Front Lever Row

Applicable to planche/handstand pushups by entering from a dip position (p.124).

### Exercise Modification (p.124-125)
[CONVENTION] Make the *easiest* portion of a movement's ROM harder, forcing full-ROM tension instead of resting at the easy end. Example (planche pushups): the lockout/top is hardest, the bottom is easiest, so drop into a harder variation's bottom position (straddle planche pushup bottom) while still finishing the rep in the easier top position (advanced tuck planche pushup lockout). Ordered example progression (p.125):
1. 3x8 Advanced Tuck Planche Pushups
2. 3x4 Advanced Tuck → Bottom Straddle Planche Pushup position
3. 3x5 (same)
4. 3x6 (same)
5. 3x7 (same)
6. 3x8 (same)
7. 3x3 Straddle Planche Pushups

[CONVENTION] Works best paired with the matching isometric of the target movement (e.g., train straddle planche isometric alongside the advanced-tuck-pushup-to-straddle-bottom work), because pushup progression level typically sits one rung below isometric progression level for the same skill line — attributed to Ido Portal for the planche application (p.125).

### Additional Sets with Decreased Rest Times (p.125-126)
[CONVENTION] Simultaneously increase set count and decrease inter-set rest to make the *current* progression "extremely easy," then move up. Mechanism, tied explicitly to strength = neural factors × cross-sectional muscle area: decreasing rest time pushes total stimulus toward the hypertrophy range (raises cross-sectional area); adding sets raises neural-factor stimulus (recruitment/rate coding); doing both at once trains both multipliers of the strength equation concurrently (p.125-126). Example progression:
1. 3x10 Pushups @3min rest
2. 4x10 Pushups @3min rest
3. 5x10 Pushups @3min rest
4. 5x10 Pushups @2min rest
5. 5x10 Pushups @1min rest

Order of manipulation (sets-first-then-rest, rest-first-then-sets, or simultaneous) is left to the athlete's own limits/judgment — no single correct order is prescribed (p.126). Second example given for planche tuck holds: 3x20s @3min rest progressing to 5x20s @1min rest to unlock advanced tuck planche (p.126).

### Hybrid Sets (p.126-127)
[CONVENTION] "Drop set" style: perform some reps of the *next* progression, immediately followed (same set) by fill-in reps of the *current* (easier) progression, to combine strength stimulus (from the hard reps) with hypertrophy-driving volume (from the fill-in reps) simultaneously. Popularized as a technique after the 1st edition (book notes this method's popularity grew post-2011). Ordered example progression (pull-ups → wide-grip pull-ups) (p.124/125 text, numbers p.125):
1. 3 sets of 10 Pull-ups
2. 3 sets of (1 Wide-Grip Pull-up + 6 Pull-ups)
3. 3 sets of (2 Wide-Grip Pull-ups + 4 Pull-ups)
4. 3 sets of (3 Wide-Grip Pull-ups + 2 Pull-ups)
5. 3 sets of (4 Wide-Grip Pull-ups + 0 Pull-ups)

Execution rule: each exercise and drop-set portion should stay slightly short of failure except the final set of the session, which can go to failure to calibrate the next workout (p.125). Progress can register in *either* half of the hybrid set — increasing wide-grip reps directly, or increasing fill-in pull-up reps at a constant wide-grip count — the latter signals rising strength reserve that should convert to wide-grip gains in later sessions. Rationale: doubles the number of trackable progress variables versus a single straight set (p.125-126).

### Hybrid Sets with Eccentrics (p.125-126, table p.126)
[CONVENTION] Same drop-set logic, but the fill-in volume is eccentrics of the harder progression rather than reps of the easier progression — used when volume of the target concentric movement is very low. Example (L-pull-ups):
1. 3 sets of (1 L-Pull-up + 5 L-Pull-up Eccentrics @5s each)
2. 3 sets of (2 L-Pull-ups + 4 Eccentrics @5s)
3. 3 sets of (3 L-Pull-ups + 3 Eccentrics @5s)
4. 3 sets of (4 L-Pull-ups + 2 Eccentrics @5s)
5. 3 sets of (5 L-Pull-ups + 1 Eccentric @5s)

Concentric count rises while eccentric fill-in count falls in lockstep — same principle also stated to work with density and tempo variants, not just eccentrics (p.126).

### Simple Hybrid Sets (p.126-127)
[CONVENTION] Simplification of hybrid sets for when combining two full movements in one set is impractical: perform maximum singles/reps of the *next* progression, then fill remaining volume with eccentrics or assisted concentrics of that *same* next progression (not the previous one). Two four-plus-workout example tracks given for the muscle-up (p.126):
1. Singles 1-1-1 + Eccentrics 3x3 @10s
2. Singles 1-1-1-1-1 + Eccentrics 3x3 @8s
3. Singles 1-1-1-1-1-1 + Eccentrics 3x3 @8s
4. Singles 2-1-1-1-1-1 + Eccentrics 2x3 @8s

(parallel track substitutes Assisted Muscle-ups for Eccentrics, same rep progression, p.126-127)

Rationale: not enough volume at the target skill to get a strength stimulus from concentrics alone, so eccentrics/assisted-concentrics of the *target* movement itself fill volume while singles count is built up; eccentric/assisted volume is trimmed as single count rises. [CONVENTION] Book's own ranking: this is described as "the best option for gaining strength among the inter-exercise progressions listed," at the cost of significantly longer sessions — recommended for athletes without time constraints (p.127).

## Complex Methods of Progression (Periodization) (p.127)

### Accumulation and Intensification (p.127-128)
[CONVENTION] Definitions tied to ch.5's micro/meso/macrocycle structure (microcycle = 1 week; mesocycle = block of microcycles ending in a deload). **Accumulation**: multiple variables (sets, reps, tempo, rest, volume) increased/loosened simultaneously to intentionally overwork the athlete — an advanced technique because ≥2 factors change within a single workout. **Intensification**: reps/sets reduced, tempo and rest shifted toward strength/hypertrophy-appropriate ranges, difficulty of exercise sharply increased — again multiple factors at once (p.127).
[CONVENTION] Characteristic parameter ranges given for attribute-specific microcycles:
- Hypertrophy-oriented: intensity 60-85% 1RM, volume 4-6+ sets × 8-12 reps, rest 2-4 min, tempo longer with pauses (example 51x1) (p.127-128).
- Strength-oriented: intensity 80-100% 1RM, volume 3-8+ sets × 1-6 reps, rest 3-5+ min, tempo short (10x0) (p.128).

These ranges are explicitly the accumulation-phase and intensification-phase profiles respectively — the book draws a direct equivalence between "accumulation" ≈ hypertrophy microcycle and "intensification" ≈ strength microcycle (p.128). Example mesocycle alternation (p.128):
- Wk1 Accumulation: Hypertrophy 8-10RM
- Wk2 Intensification: Strength 4-6RM
- Wk3 Accumulation: Hypertrophy 8-10RM
- Wk4 Intensification: Strength 4-6RM
- Wk5 Accumulation: Hypertrophy 8-10RM
- Wk6 Intensification: Strength 4-6RM

[CONVENTION] Recommended sequencing: schedule accumulation before intensification on the same exercises within a mesocycle (p.129).

### Light/Heavy Model (p.129-130)
[CONVENTION] Same accumulation/intensification logic but applied *intra-weekly* (alternating within the week) rather than *inter-weekly* (block-by-block). Light day = low intensity, fewer sets, more reps; heavy day = high intensity, more sets, fewer reps. Book states most "modern" periodization favors intra-weekly over inter-weekly variation. Works well for intermediates (p.129).
[CONVENTION] Mechanism tying the two lines of progress together, via strength = neural adaptations × cross-sectional muscle area: strength-day work drives neural adaptations; hypertrophy-day work drives cross-sectional area; increased CSA also supports higher strength-day loads, and increased strength lowers the *relative* intensity of a given bodyweight rep, supporting more hypertrophy-day reps — the two qualities feed each other cyclically (p.129-130). Example 6-workout progression (pull-ups): Mon Hyp 3x10 → Wed Str 3x5+20lb → Fri Hyp 3x11 → Mon Str 3x5+25lb → Wed Hyp 3x12 → Fri Str 3x5+30lb (p.130). Not mandatory to run two separate lines of progress — once strong enough, both the 3-5x5 and 3x10 days can progress by adding weight to both; heuristic given: the 10-rep day's load typically lags the 5-rep day's load by ~20-30lb (p.130).
[CONVENTION] Quantified expectation over a 6-week/9-workout-per-quality mesocycle: full success on 9 strength workouts ≈ +40-45lb on one exercise; full success on 9 hypertrophy workouts ≈ +9 reps on one exercise. Book caveats this can't continue indefinitely, but even half this rate over six weeks is "extremely good progress for most athletes" — called an "extremely effective intermediate technique" (p.130).

### Modern Periodization / Daily Undulated Periodization (DUP) (p.130-132)
[CONVENTION] Periodization defined broadly as varying volume/intensity/frequency (and tempo/rest) to sustain gains and avoid plateaus. Traditional (inter-weekly block) periodization is deemed inferior to modern (intra-weekly) methods by the book, though the underlying variables are the same (p.131).
[SCIENCE via ch.1 SAID principle] Modern (intra-weekly) periodization is argued superior to traditional block periodization because by the time a traditional cycle reaches its strength/power block, weeks have elapsed since the hypertrophy/preparatory block, and specific adaptations from those earlier phases have begun to decay; intra-weekly rotation keeps all qualities trained every week, blunting adaptation loss between phases (p.131).
[CONVENTION] DUP explicitly gated by training level: **not for beginners** (undermines simpler linear-progression methods, which work better for them) and **not for elite athletes** (who need conjugate or concurrent models instead) — DUP is positioned specifically for the advanced-strength range, and is favored here for ease of implementation (p.131).
[CONVENTION] Recommended DUP structure: 3 workouts/week, essentially light/heavy expanded to three tiers, e.g. (p.131):
1. Monday: 3x8-10 all exercises
2. Wednesday: 3-5x5 all exercises
3. Friday: 5-8x3 all exercises

Difficulty of the *exercise itself* (progression choice), not just load, can be the varied dial — example: full front lever pull-up 3x8 unattainable Monday → drop to straddle front lever pull-up 3x8; Wednesday drop to straddle + added weight for 4x5; Friday full front lever achievable at 4x3 (p.132).
[CONVENTION] 4-day/week variants offered as options (not standard): double light/heavy (3x8-10 / 5x5 / 3x6-8 / 6x3), or modified-frequency schedules like 3/1/2/1 (3 on, 1 off, 2 on, 1 off) or 5/2, e.g. reps sequence 3x8, 3x5, 5x3, 3x8, 5x3 (p.132).
[CONVENTION] Recommended baseline rep-range tiers for DUP: high-rep day 8-10, medium-rep day 5-7, low-rep day 3-4, ordered across the week from musculoskeletal focus (early week) to neural-adaptation focus (late week) — again tied to strength = neural adaptations × muscle CSA (p.132). Individual variation acknowledged: some athletes do better on 8-10/5-7 only, or 8-10/3-4 only, or a 15→10→5 spread; book notes (based on observation, not cited research) genetically gifted athletes tend to do better with lower rep ranges (p.132-133).
[CONVENTION] Muscle-group-specific rep range adjustment: posture/postural-endurance muscles (core, back) and low-level-activity muscles (calves, forearms) — composed of more slow-twitch fiber — respond better to higher ranges: 15+ on high-rep days, 5-8 on low-rep days. Multi-joint muscles (hamstrings, glutes, biceps) respond better to 8-10 high / 3-5 low (p.133).
[CONVENTION] Practical starting templates for those without established preference: 3x10/3x7/5x3 or 3x12/3x8/4x4; recommendation to experiment over "a few different six-week cycles" followed by a rest break to find individual response. If undecided, plain DUP run M/W/F is stated to work well specifically for iron-cross-level progressions and exercises at that skill tier (p.133).

### Concurrent Periodization (p.133-134)
[CONVENTION] Framed as the answer to a stated irony: athletes who already carry high strength/muscle mass struggle to improve *all* exercises simultaneously — concurrent periodization manages this via recovery sequencing. Method: instead of stacking all heavy push/pull/legs work onto the same day (maximal single-day systemic load, hard to recover from), offset intensity across push/pull/legs so each muscle group's heavy day lands on a different calendar day. Contrast given (p.134):
- Naive: Mon Light-Push/Light-Pull/Light-Legs; Wed Medium/Medium/Medium; Fri Heavy/Heavy/Heavy (all groups peak same day)
- Concurrent: Mon Heavy-Push/Medium-Pull/Light-Legs; Wed Light-Push/Heavy-Pull/Medium-Legs; Fri Medium-Push/Light-Pull/Heavy-Legs (peaks staggered by group)

Rationale: light day trains hypertrophy/endurance, medium day trains hypertrophy-strength or power, heavy day trains pure strength — spreading these across muscle groups per day is more recovery-effective than concentrating one quality (e.g. all strength work) onto a single day system-wide (p.134). Works best applied in mesocycle-length "blocks" — exercises cycled in/out with deloads built into the mesocycle, effectively nesting multiple accumulation/intensification phases inside one mesocycle (p.134).

### Conjugate Periodization (p.134-135)
[CONVENTION] Named as one of the most advanced periodization methods; Westside Barbell cited as the exemplar. Core idea: improve one lift/skill intensively while merely *maintaining* all others, because at elite levels the stimulus needed for adaptation is so large that recovery becomes the binding constraint — all recovery capacity gets funneled to the single main lift. Maintenance of other lifts is achieved by reducing main-lift frequency (e.g., trained only once/week) while increasing supplemental/isolation volume around it (p.135). Example: bench press trained once weekly at extreme intensity, supported by dip work, tricep pressdowns, other isolation accessory work to keep the muscles primed between main-lift sessions (p.135).
[CONVENTION] Westside's dynamic-effort (DE) / maximal-effort (ME) split: DE days use lighter load with emphasis on bar speed to train neurological/rate factors for strength without the systemic cost of a true maximal lift; ME days train true maximal grinding strength (p.135).
[CONVENTION] Bodyweight application: focus all training on one advanced skill (e.g. planche or inverted cross on rings) while merely maintaining pulling/leg work — minimal isometric holds (back lever, front lever, iron cross) plus scapular-strength supplemental work. Book gates this to athletes working "beyond C-level" or elite isometric holds — i.e., not a general-audience technique (p.135).
[CONVENTION] Multiplicative-variation framing for elite training: one movement can be loaded with high frequency + high volume + high intensity simultaneously while other movements get only light/medium levels across those same three dials — tradeoffs become mandatory at elite levels, and knowing when to adjust frequency/volume/intensity per-movement becomes the core skill (p.135).
[DISPUTED/framing note] Book states explicitly that once an athlete requires this level of individualized periodization knowledge, "Overcoming Gravity will no longer be able to function as your coach" — the athlete will know more about their own individual response than any generic resource, hence the strong recommendation to log all workouts/methods over time to self-derive future programming, absent an elite-experienced personal coach (p.135-136). External reference cited for further reading: elitefts.com periodization-methods overview (p.136).

## Chapter 10 Summary (book's own recap, p.135-136)

**Simple Intra-Exercise Progressions:** Linear Progression (add weight) · Linear Repetition Progression (add reps to all sets) · Repetition Addition (add reps to single/multiple sets) · Last Set to Failure (add a rep to all sets once the failure set beats prior sets by ≥2 reps) · Additional Set (add a set) · Rest Pause (failure set + short-rest bonus rep, eliminate rest over time) · Density (decrease rest between sets) · Tempo Change (lengthen concentric/eccentric from 10x0) · Frequency Modifications (GTG / higher weekly frequency) · Transference (same methods apply to isometric/eccentric work; results don't have to look numerically "clean").

**Simple Inter-Exercise Progressions:** Weight Addition (load the easier progression) · Assistance (bands/pulleys ease the harder progression) · Eccentrics (bridge via eccentrics of the next progression) · Momentum and Extra Range (borrow momentum/ROM to bridge) · Exercise Modification (make the easy ROM portion harder via body-position change) · Additional Sets and Decreased Rest Times (raise sets, cut rest on either progression) · Hybrid Sets (next-progression reps + previous-progression drop-set fill, like a drop set) · Simple Hybrid Sets (max reps of next progression + eccentric/assisted fill of that same progression).

**Complex Methods of Progression:** Accumulation and Intensification (weekly block ordering: high-volume/high-rep block then higher-intensity/lower-rep, harder-exercise block) · Light/Heavy (alternate rep scheme and intensity by day within the week) · DUP (light/medium/heavy day rotation to raise strength and hypertrophy together) · Concurrent and Conjugate Systems (alternative periodization schedules working different attributes simultaneously — either maintaining some while improving others, or improving several at once).
